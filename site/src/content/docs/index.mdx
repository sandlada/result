`@sandlada/result` replaces `throw`/`catch` for predictable failures with a discriminated union the
compiler tracks. Success and failure both travel as plain objects, so a function signature tells you
whether it can fail. The library is fully generic over `TError`, ships as ESM across 14 subpaths, and
has zero dependencies.

## Install

```bash
npm i @sandlada/result
```

:::caution[ESM only]
The package cannot be loaded with `require()`. Your project must use ESM (`import`) or dynamic `import()`.
:::
